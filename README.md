# ThreeChess (大力推荐!)

<br>
<br>

# 简介
## 下载: https://github.com/BProbie/mcplugin/tree/ThreeChess/release
## 功能: 三子棋小游戏
## 插件目的: 以小游戏的形式增加玩家间的有趣互动
## 游戏版本: 1.21
## 插件版本: 1.0
## 插件作者: Probie

<br>
<br>

# 使用方法
## 指令: /threechess-invite [player] 向玩家发送三子棋邀请
## 指令: /threechess-accept 接受玩家的三子棋邀请
## 指令: /threechess-size 查看当前棋盘大小
## 指令: /threechess-size [3-6] 设置当前棋盘大小 (需要OP权限)

<br>
<br>

# 推荐理由
## 避免了传统的数据处理逻辑而产生不必要的混淆及错误
## 原创了一个独特的新型数据处理逻辑系统
## 将数据打包成数据包形成响应式数据包处理流程
## 直接与内存进行交互避免了网络IP等不安全的交互传输
## 然后再将数据直接渲染到游戏UI上操作
## 稳定！高效！简约！
