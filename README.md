# LuckyTime 幸运时刻插件

一个Minecraft Spigot插件，定期向在线玩家发放随机幸运物品！

## 🎯 功能特点

- 🎁 **定时幸运物品**: 每隔一段时间自动向在线玩家发放随机物品
- 🔧 **可配置间隔**: 管理员可以自定义发放物品的时间间隔
- 🔊 **广播通知**: 发放物品时会向所有玩家广播通知并播放音效
- 👋 **欢迎消息**: 玩家加入服务器时会收到插件运行提示
- 💾 **配置保存**: 插件会保存配置，确保重启后设置不丢失

## 📦 安装说明

1. 确保您的Minecraft服务器使用的是**Spigot/Paper 1.21**版本
2. 下载`LuckyTime-1.0-SNAPSHOT-shaded.jar`文件
3. 将jar文件放入服务器的`plugins`文件夹中
4. 重启服务器以加载插件
5. 享受幸运时刻！

## 🎮 命令使用

| 命令 | 描述 | 权限要求 |
|------|------|----------|
| `/luckytime` | 查看当前幸运间隔时间 | 所有人 |
| `/luckytime set <秒数>` | 设置幸运物品发放间隔 | OP权限 |

### 示例

- 查看当前间隔: `/luckytime`
- 设置间隔为5分钟: `/luckytime set 300`
- 设置间隔为15分钟: `/luckytime set 900`

## ⚙️ 配置说明

插件会自动在服务器目录下创建`LuckyTime.config`配置文件

**默认设置:**
- 幸运时间间隔: 600秒 (10分钟)
- 物品最小数量: 1个
- 物品最大数量: 3个
- 随机物品池: Minecraft所有可作为物品的材料

## 🔍 工作原理

1. 插件启动时初始化配置和定时任务
2. 每秒检查所有在线玩家的游戏时间
3. 当玩家的游戏时间达到幸运间隔时，随机发放1-3个物品
4. 向所有玩家广播获得物品的消息并播放升级音效
5. 重置该玩家的游戏时间计数，等待下一次幸运时刻

## 📝 注意事项

- 请确保玩家背包有足够空间接收幸运物品
- 只有OP权限的玩家可以修改幸运时间间隔
- 插件会自动保存配置，无需手动备份
