# GuessNumber

<br>
<br>

# 简介
## 下载: https://github.com/BProbie/mcplugin/tree/GuessNumber/release
## 功能: 聊天栏猜数字小游戏
## 插件目的: 以小游戏的形式增加玩家的互动体验
## 游戏版本: 1.21
## 插件版本: 1.0
## 插件作者: Probie

<br>
<br>

# 使用方法
## 指令: /guess-num start 开始游戏循环
## 指令: /guess-num restart 重启游戏 (需要OP权限)
## 指令: /guess-num stop 关闭游戏循环 (需要OP权限)
## 指令: /guess-num delay 查看游戏循环事件间隔
## 指令: /guess-num range 查看数字范围
## 指令: /guess-num delay [num] 设置游戏循环事件间隔 (需要OP权限)
## 指令: /guess-num range [num] 设置数字范围 (需要OP权限)
